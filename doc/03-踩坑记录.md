## 快速避雷清单

1. LED：永远看引脚，别信枚举名。
2. 语音 ID：改协议先核对 `Bsp_UartAsr.h` + `cmd_to_voice[]`。
3. 时间：别引入阻塞大延时，用 `Bsp_Tick_*`。
4. 新增 BSP：改 `Bsp.h` 汇总 include + `XiaoBai.uvprojx` 加文件，否则编译不过。
5. 编译：AC5 专用工程，0 Error 0 Warning 是门禁。
