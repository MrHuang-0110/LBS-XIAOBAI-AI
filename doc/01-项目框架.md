# 01 — 项目框架

「小白-Ai」AI 玩具小车主控固件。主控 **PY32F030K28U6TR**（Cortex-M0+，Flash 32KB @0x08000000，RAM 4KB @0x20000000，HSI/HSE 24MHz）。裸机（无 RTOS），单 `while(1)` 主循环轮询 + 中断置标志。产品形态：语音对话 + 双电机小车 + BLE 遥控 + 8×14 点阵眼睛屏。

## 硬件拓扑

| 外设 | 引脚 | 连接 | 说明 |
|---|---|---|---|
| USART1 | PB6=TX / PB7=RX (AF0) | ECB00CV2 BLE 芯片 | 9600 8N1，DMA 收 + IDLE 中断 |
| BLE STA | PF3 输入（下拉） | ECB00 STA | 电平判连接：高=已连接 |
| USART2 | PF0=TX / PF1=RX | ASRPRO 语音芯片 | 9600 8N1，DMA 收 + IDLE 中断，ASCII 协议 v0.7 |
| 电机 | TIM3 4 通道 | 双电机 | PWM 20kHz，方向+速度档 |
| LED×4 | PB2/PA10/PA11/PA12 | KEY 一一对应 | 模式指示（见下方坑 1） |
| 呼吸/心跳 | PA8 常亮 + PA9 呼吸 | 开机灯 | 唤醒启动，15s 超时自关 |
| 按键×4 | PB3/PB4/PB5/PB8 | 外部上拉 | KEY1 兼开机确认/长按关机 |
| 电源锁存 | PA15 | MOS 锁存 | 置 0 = 关机 |
| TM1640 | GPIO 模拟 | 8×14 点阵眼睛 | 16 列芯片仅用 14 列 |
| 红外×3 / 电量 | ADC | 反射传感器 / 分压 | ADC<3000=有反射（遮挡~200，无~4000） |

## 软件分层（自底向上）

```
User/                   应用层：入口 main.c + App_Main 主循环调度 + 各职责模块
                        （App_Mode* 模式状态机 / App_Vehicle 车辆动作 /
                         App_Eye 眼睛 / App_Breath 呼吸 / App_Shutdown 关机 /
                         App_Battery 电池 / App_System 时钟）
Protocol/               协议层：Proto_Asr 语音协议（ID 宏 + cmd_to_voice 映射）、
                        Proto_Remote 遥控帧协议（帧校验 + 按键位图）
BSP_Drivers/            驱动层：每外设一子目录，Bsp.c 汇总 BSP_Init()
PY32F0xx_HAL_Driver/    普冉官方 HAL/LL（供应商代码，一般不改）
CMSIS/                  ARM 头文件 + 启动文件 startup_py32f030x6.s
```

## 核心模块

- `User/main.c` — 入口（5 行）：`HAL_Init()` → `App_System_Init()` → `BSP_Init()` → `App_Init()` → `App_Loop()`（不返回）；全部应用逻辑下沉到 App_*/Proto_* 模块。
- `User/App_Main.c` — 主循环调度：`while(1)` 轮询按键/语音/遥控/感应事件，驱动眼睛/呼吸/低电量。
- `User/App_Mode*.c` — 4 模式状态机（语音/动力/感应/遥控），每模式进入播报对应语音、点亮对应 LED（`mode_led[]`/`mode_voice[]`/`sensor_voice[]` 查表）。
- `User/App_Vehicle.c` / `App_Eye.c` / `App_Breath.c` / `App_Shutdown.c` / `App_Battery.c` / `App_System.c` — 车辆动作 / 眼睛动画 / 呼吸灯 / 关机流程 / 低电量 / 系统时钟等职责模块。
- `Protocol/Proto_Asr.c` — 语音协议 v0.7：ID 宏（`ASR_CMD_*` 1-16 / `ASR_VOICE_*` 17-41）+ `cmd_to_voice[]` 权威映射。
- `Protocol/Proto_Remote.c` — 遥控帧解析闭环：17 字节帧校验（`5A 97 98 0A C1 + 10 键位图 + CRC + A5`）+ 按键位图 → 事件回调。
- `BSP_Drivers/Bsp.c` — `BSP_Init()` 固定顺序：Tick→Led→Power(2s 确认，失败死循环)→LedPwm→Key→Motor→Adc→IR→Battery→UartAsr→UartBle→Tm1640(清屏)。
- `BSP_Drivers/Bsp_UartAsr/` — 语音芯片串口驱动（DMA 收 + IDLE 中断），事件轮询 `Bsp_UartAsr_TryRecv()`；协议宏已上移 Proto_Asr.h。
- `BSP_Drivers/Bsp_UartBle/` — BLE 透传 + 遥控帧字节流接收（帧校验上移 Proto_Remote）。
- `BSP_Drivers/Bsp_Tm1640/` — 眼睛动画画布（眨眼/瞳孔移动由 App_Eye 驱动）。

## 数据流

- **事件采集**：按键/语音/遥控 → 中断或轮询置标志 → 主循环 `while(1)` 逐段处理（按键→语音→遥控→感应→眼睛→呼吸→低电量）。遥控帧由 Proto_Remote 解析后交给 App_Mode_Remote。
- **时间基准**：`Bsp_Tick_GetMs()`（Systick，非阻塞）；短延时用 `Bsp_Tick_DelayMs()`。
- **中断转发**：`User/py32f0xx_it.c` 只做转发，实现在 BSP 的 `*_IRQHandler()`。
