# 02 — 技术栈

## 硬件

| 项 | 值 |
|---|---|
| MCU | 普冉 PY32F030K28U6TR（Cortex-M0+，无 FPU/DSP，48MHz max） |
| 资源 | Flash 32KB（0x08000000-0x08007FFF），RAM 4KB（0x20000000-0x20000FFF） |
| 时钟 | HSI/HSE 24MHz（`py32f0xx_hal_conf.h`），实际系统时钟见 `APP_SystemClockConfig()` |
| 配套芯片 | ASRPRO 语音识别、ECB00CV2 BLE 透传、TM1640 LED 驱动 |

## 工具链（构建环境，勿随意变更）

| 项 | 值 |
|---|---|
| IDE | Keil uVision5（工程 `MDK-ARM/XiaoBai.uvprojx`，Target `PY32F030_Project`） |
| 编译器 | **ARM Compiler V5.06 update 7 (build 960)，AC5**（`uAC6=0`）⚠️ 不要切换 AC6 |
| 器件包 | Puya.PY32F0xx_DFP.1.1.9 |
| 编译宏 | `USE_HAL_DRIVER,PY32F030x6`；C99；Warning Level 2 |
| 输出 | `MDK-ARM/Output/XiaoBai.hex`（烧录）/ `.axf` / `.map` |
| 烧录 | Keil SWD（UL2CM3，PY32F0xx_32.FLM） |

命令行编译：`UV4 -b MDK-ARM/XiaoBai.uvprojx -j0 -o build.log`（需 Keil 安装目录的 UV4.exe）。

## 软件库

- **PY32F0xx HAL/LL**（普冉官方，STM32 HAL 风格）— 启用模块（`py32f0xx_hal_conf.h`）：RCC/ADC/COMP/FLASH/GPIO/TIM/DMA/PWR/I2C/UART/SPI/LED/EXTI/CORTEX；禁用的：CRC/IWDG/WWDG/LPTIM/RTC。
- **CMSIS** 5.1.2（core_cm0plus 等）+ DSP Lib（未启用实际使用）。

## 外设与通信协议

| 协议 | 版本/格式 | 权威文档 |
|---|---|---|
| 语音芯片交互 | **v0.7** ASCII：MCU 发 `play=NN\n`（帧尾 `\n`），收帧尾 `\r\n`；命令 ID 1-16，播报 ID 17-41 | `resource/语音芯片交互协议.md`（工作区外） |
| BLE 透传 | ECB00 默认从机透传，AT 以 `\r\n` 结尾；连接态用 PF3 电平，不用字符串 | ECB00 datasheet |
| 遥控帧 | 17B：`5A 97 98 0A C1 + 10B 键位图 + CRC(A5前累加和低8位) + A5` | `resource/遥控协议.md` |
| 电机 | TIM3 4 通道 PWM 20kHz；档位 1=40% / 2=70% / 3=100% | — |

## 约定速查

- 命名：`Bsp_<模块>_<动作>()`、类型 `Bsp_Xxx_Type_t`、枚举值大写。
- 时间：一切非阻塞，主循环轮询；`Bsp_Tick_*` 为唯一时间基准。
- 文档缺口：`../docs/plan-bsp-v1.md`、`../resource/小白IO分配.xlsx` 在工作区外，本机路径 `E:\LBS-XIAOBAI-AI` 上级目录。
