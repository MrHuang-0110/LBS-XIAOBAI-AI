# 小白机器人眼睛点阵动画 V0.2

这套资源包含 10 种双眼动态表情：待机、开心、生气、伤心、惊讶、眨眼、喜欢、晕眩、困倦、好奇。

## ID 与选项名称

| ID | 选项名称 |
| --- | --- |
| EYE_01 | 待机 |
| EYE_02 | 开心 |
| EYE_03 | 生气 |
| EYE_04 | 伤心 |
| EYE_05 | 惊讶 |
| EYE_06 | 眨眼 |
| EYE_07 | 喜欢 |
| EYE_08 | 晕眩 |
| EYE_09 | 困倦 |
| EYE_10 | 好奇 |

## 查看效果

- `V0.2动态预览.html`：可持续播放全部 10 种表情，适合评审动作节奏。
- `V0.2十种眼部表情动态预览.gif`：全部表情的动态总览。
- `01_idle.gif` 至 `10_curious.gif`：每种表情的独立动画。

## 开发文件

- `V0.2动画帧.json`：上位机、Android 或跨平台程序使用。

每只眼睛为 7×7 点阵，左上、右上、左下、右下四个位置不存在，所有动画数据中均固定为 0。每一行用 7 位表示，最左侧 LED 为 bit6，最右侧 LED 为 bit0。每帧带有 `duration_ms`，左右眼数据分别存放。

`EYE_01` 至 `EYE_10` 与 JSON 中的内部数值 1–10 一一对应。上位机可按 `option_id` 选择表情，再按照各帧的 `duration_ms` 依次播放左右眼点阵数据。
